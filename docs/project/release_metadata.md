## Full Description

**Japanese**:
「デジタルおみくじ」は、スマートフォンの加速度センサーを活用したおみくじエンタメアプリです。
神社の雰囲気を再現したデザインと、心地よい触覚フィードバック（ハプティクス）で、気軽に楽しめるおみくじ体験を提供します。

### 主な機能

- **振って引く**: スマホを振る動作でおみくじを引くことができます。
- **美しい演出**: 結果が表示されるまでのワクワク感を高めるアニメーション。
- **履歴機能**: 過去に引いたおみくじの結果をいつでも振り返ることができます。
- **多言語対応**: 日本語と英語に対応。海外の方への紹介にも最適です。
- **プライバシー重視**: 個人情報は収集しません。安心してお使いいただけます。

毎日のちょっとした運試しや気分転換に。「デジタルおみくじ」で楽しいおみくじ体験をどうぞ。
※本アプリは娯楽目的です。実際の占い・鑑定ではありません。

---

**English**:
"Digital Omikuji" is an entertainment app that uses your smartphone's accelerometer for a fun Omikuji experience.
With a design inspired by Japanese shrine atmosphere and pleasant haptic feedback, it offers an enjoyable digital fortune-drawing experience.

### Key Features

- **Shake to Draw**: Draw a fortune by physically shaking your phone.
- **Beautiful Effects**: Animations that build anticipation before the result is revealed.
- **History**: Review your past fortune results at any time.
- **Multi-language**: Supports Japanese and English. Great for introducing Japanese culture.
- **Privacy First**: No personal data is collected. Use with peace of mind.

A fun daily ritual or a change of pace. Enjoy the "Digital Omikuji" experience!
\*This app is for entertainment purposes only. Not actual fortune-telling.
