# Defect Analysis

## Purpose

不具合の事象と根本原因を整理し、再発防止につながる学びを残す。

## Checkpoints

- 事象と再現条件が明確か
- 影響範囲が整理されているか
- 直接原因と根本原因が分離されているか
- 再発防止策が具体的か
- テストや運用へ反映できるか

## Output Format

- Summary
- Incident Timeline
- Root Cause
- Impact
- Preventive Actions
