# Test Strategy Review

## Purpose

テスト全体の役割分担が妥当で、抜けや重複がないかを評価する。

## Checkpoints

- 単体、統合、E2E の責務分担が自然か
- 重要ロジックに対するテストがあるか
- UI 依存が強すぎないか
- 失敗系や境界条件があるか
- 保守コストと検出力の釣り合いが取れているか

## Output Format

- Summary
- Strategy Findings
- Risks
- Recommended Coverage
- Decision
