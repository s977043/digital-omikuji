# Design Token Governance

## Purpose

デザイントークンが体系的に使われ、場当たり的な値の直書きが増えていないかを評価する。

## Checkpoints

- raw value が直書きされていないか
- token 命名が意味ベースか
- semantic token の追加が妥当か
- 既存 token の再利用で足りないか
- Figma と実装の token 語彙が噛み合っているか

## Output Format

- Summary
- Token Findings
- Risks
- Governance Recommendations
- Decision
