# State Management Review

## Purpose

状態管理が過剰でも不足でもなく、変更しやすい構造になっているかを評価する。

## Checkpoints

- 状態の所有者が自然か
- 派生値と真の状態が混ざっていないか
- 画面とロジックの責務が分離されているか
- 更新フローが追いやすいか
- テストしやすい形か

## Output Format

- Summary
- State Findings
- Risks
- Refactoring Ideas
- Decision
