# Component Design Review

## Purpose

コンポーネントの責務と API が自然で、再利用しやすく、保守しやすいかを評価する。

## Checkpoints

- 単一責務が守られているか
- props 命名が分かりやすいか
- variant が用途に対して過剰でないか
- 構成要素が分離可能か
- テストしやすい構造か

## Output Format

- Summary
- Component Findings
- Risks
- Refactoring Recommendations
- Decision
