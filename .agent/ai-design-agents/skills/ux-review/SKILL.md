# UX Review

## Purpose

ユーザーが迷わず目的に到達できるか、途中で詰まる場所がないかを評価する。

## Checkpoints

- 目的到達までの手順が自然か
- 情報量や選択肢が過剰でないか
- 初見で理解しづらい箇所がないか
- エラーや空状態から復帰できるか
- 画面単位ではなくフロー全体で整合しているか

## Output Format

- Summary
- Findings
- Risks
- Recommended Changes
- Decision
