# Repo Structure Review

## Purpose

リポジトリ構成がチーム運用と責務分離に合っているかを評価する。

## Checkpoints

- ディレクトリ構成が役割を表しているか
- 近い責務のコードが近くにあるか
- ドキュメントの正本が分かるか
- 変更時の探索コストが高すぎないか

## Output Format

- Summary
- Structure Findings
- Risks
- Reorganization Suggestions
- Decision
