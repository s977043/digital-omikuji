# Accessibility Audit

## Purpose

画面・コンポーネントがアクセシビリティ基準を満たしているか確認する。

## Checkpoints

- キーボード操作可能
- ラベル付与
- 見出しや意味構造
- コントラスト
- エラー説明
- スクリーンリーダーで理解可能

## Output Format

- Summary
- Violations
- Severity
- Fix Recommendations
- Decision
