# Observability Review

## Purpose

障害の検知、切り分け、追跡に必要な観測性が確保されているかを評価する。

## Checkpoints

- 主要イベントが記録されるか
- 失敗時のログが十分か
- メトリクスやトレースが必要な箇所が見えているか
- アラート条件が運用可能か
- ダッシュボードや調査導線があるか

## Output Format

- Summary
- Observability Findings
- Risks
- Missing Signals
- Decision
