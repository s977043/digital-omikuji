# Quality Gate Review

## Purpose

リリース可否判断に必要な品質条件の充足状況を評価する。

## Checkpoints

- 必須テスト完了
- 重大不具合未解消有無
- 回帰リスク明示
- a11y / performance / security 影響確認
- 受け入れ条件達成
- 例外事項の承認有無

## Output Format

- Summary
- Gate Status
- Missing Criteria
- Risks
- Decision
