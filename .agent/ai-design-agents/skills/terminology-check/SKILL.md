# Terminology Check

## Purpose

用語の揺れや誤用を減らし、ユーザー向け文言と開発用語の一貫性を保つ。

## Checkpoints

- 同じ概念に複数の呼び方がないか
- 社内用語がユーザー向け画面に漏れていないか
- 略語が説明なしに出ていないか
- エージェント出力と標準用語が一致しているか

## Output Format

- Summary
- Terminology Findings
- Risks
- Preferred Terms
- Decision
