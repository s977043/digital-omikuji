# Architecture Review

## Purpose

システム構造、責務分離、依存方向、拡張性を評価する。

## Checkpoints

- レイヤーが明確か
- 責務境界が妥当か
- 依存関係が一方向か
- モジュール分割が自然か
- 将来の変更に耐えられるか
- 運用や監視と矛盾しないか

## Output Format

- Summary
- Architecture Findings
- Dependency Risks
- Structural Recommendations
- Final Decision
