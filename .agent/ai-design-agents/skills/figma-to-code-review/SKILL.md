# Figma to Code Review

## Purpose

Figma と実装の差分を、単なる一致判定ではなく、意図の再現と運用のしやすさの観点で評価する。

## Checkpoints

- 情報階層が Figma の意図を保っているか
- spacing、typography、color の差分が許容範囲か
- 実装都合の差分に説明があるか
- 既存コンポーネントへの落とし込みが妥当か
- 状態差分やレスポンシブ差分が考慮されているか

## Output Format

- Summary
- Visual Differences
- Risks
- Mapping Recommendations
- Decision
