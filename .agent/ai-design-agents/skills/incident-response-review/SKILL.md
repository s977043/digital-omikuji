# Incident Response Review

## Purpose

障害発生時に迷わず初動できるよう、対応フローと必要情報の揃い具合を評価する。

## Checkpoints

- 初動手順があるか
- 連絡先や責任分担が明確か
- 影響判定手順があるか
- ロールバック判断に必要な情報があるか
- 振り返りと再発防止へ繋げられるか

## Output Format

- Summary
- Incident Risks
- Missing Response Items
- Recommended Actions
- Decision
