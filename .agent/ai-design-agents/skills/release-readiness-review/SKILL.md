# Release Readiness Review

## Purpose

リリース可否判断の前に、未確認項目と既知リスクが整理されているかを評価する。

## Checkpoints

- リリース対象が明確か
- 必須確認項目が完了しているか
- 既知リスクが共有可能な形か
- 受け入れ条件が満たされているか
- 例外対応が定義されているか

## Output Format

- Summary
- Readiness Findings
- Risks
- Missing Checks
- Decision
