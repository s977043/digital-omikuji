# Microcopy Review

## Purpose

画面文言が短く明確で、ユーザーの次アクションを支援できているかを評価する。

## Checkpoints

- CTA が行動を促しているか
- エラー時に次アクションが分かるか
- 空状態が放置感を生まないか
- 文言が冗長でないか
- トーンが一貫しているか

## Output Format

- Summary
- Copy Findings
- Risks
- Rewrite Suggestions
- Decision
