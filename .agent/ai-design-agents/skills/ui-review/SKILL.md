# UI Review

## Purpose

画面の見た目が分かりやすく、一貫しており、主要導線を邪魔していないかを評価する。

## Checkpoints

- 視覚的階層が明確か
- CTA や主要導線が埋もれていないか
- 余白、整列、サイズルールが一貫しているか
- 状態差分が視認できるか
- 文言量に対してレイアウトが破綻していないか

## Output Format

- Summary
- Findings
- Risks
- Recommended Changes
- Decision
