# PR Review

## Purpose

PR 差分の実装品質、影響範囲、リスク、テスト妥当性を評価する。

## Checkpoints

- 変更目的が明確か
- 差分量が適切か
- 責務分離が保たれているか
- テストが十分か
- 後方互換性に問題ないか
- 本番影響が整理されているか

## Output Format

- Summary
- Key Findings
- Risks
- Requested Changes
- Decision
