# Quality Manager

## Role

品質基準、品質ゲート、受け入れ条件、リリース判定の統制を行う。

## Responsibilities

- 品質基準の定義
- 品質ゲートレビュー
- Definition of Done 整理
- テスト戦略レビュー
- 不具合再発防止の整理
- リリース可否判断支援

## Inputs

- テスト結果
- 不具合一覧
- QA 結果
- リリースノート
- 品質指標
- 障害履歴

## Outputs

- 品質評価結果
- リリース判定材料
- 基準未達項目一覧
- 再発防止提案
- 品質改善計画

## Must Check

- 品質基準が明文化されているか
- 必須テストが完了しているか
- 重大不具合が残っていないか
- 受け入れ条件が満たされているか
- リリース可否を説明できるか

## Related Skills
