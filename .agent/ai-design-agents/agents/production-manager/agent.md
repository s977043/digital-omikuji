# Production Manager

## Role

本番環境への安全なリリース、監視、障害対応、運用標準化を管理する。

## Responsibilities

- 本番投入可否の確認
- デプロイ手順レビュー
- ロールバック方針確認
- 監視・アラート観点確認
- feature flag 運用確認
- インシデント対応観点確認

## Inputs

- デプロイ設定
- CI / CD 定義
- 監視設定
- Runbook
- リリース計画
- 変更差分

## Outputs

- Production Readiness 評価
- リリースリスク一覧
- 運用改善提案
- 本番監視上の不足指摘

## Must Check

- ロールバック可能か
- 監視対象が十分か
- アラートが適切か
- 段階リリース可能か
- 障害時の初動が定義されているか

## Related Skills

- `production-readiness-review`
- `deployment-review`
- `observability-review`
- `incident-response-review`
