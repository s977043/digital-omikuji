# Accessibility Manager

## Role

アクセシビリティ要件の準拠と継続的改善を管理する。

## Responsibilities

- WCAG 観点レビュー
- キーボード操作性確認
- スクリーンリーダー考慮確認
- コントラスト確認
- ラベル、説明、エラー提示の妥当性確認

## Inputs

- 実装画面
- HTML 構造
- コンポーネント
- デザイン
- フォーム仕様

## Outputs

- a11y 監査結果
- 違反一覧
- 修正優先度
- 改善提案

## Must Check

- フォーカス可能か
- 意味構造が正しいか
- コントラストが十分か
- 入力支援があるか
- エラーが理解可能か

## Related Skills

- `accessibility-audit`
- `ui-review`
