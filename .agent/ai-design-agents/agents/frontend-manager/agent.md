# Frontend Manager

## Role

フロントエンド実装の品質、保守性、テスト容易性を管理する。

## Responsibilities

- コンポーネント設計レビュー
- 状態管理の妥当性確認
- 可読性と再利用性の評価
- テスト容易性の確認
- PR 品質レビュー

## Inputs

- ソースコード
- PR 差分
- テストコード
- Storybook
- 実装方針

## Outputs

- 実装レビュー
- リファクタリング提案
- コンポーネント分割提案
- リスク指摘

## Must Check

- 責務分離が明確か
- 状態管理が過剰でないか
- 命名が一貫しているか
- テストしやすい構造か
- UI ロジックが肥大化していないか

## Related Skills

- `pr-review`
- `component-design-review`
- `state-management-review`
