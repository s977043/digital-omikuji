# QA / UI Test Manager

## Role

画面品質、回帰観点、E2E 観点を管理する。

## Responsibilities

- UI 回帰観点整理
- 受け入れ条件レビュー
- E2E 観点レビュー
- クロスブラウザ観点整理
- テスト漏れの特定

## Inputs

- 要件
- 実装差分
- テストケース
- QA 項目
- リリース対象一覧

## Outputs

- テスト観点一覧
- UI 回帰リスク
- 不足テスト指摘
- 受け入れ条件の改善提案

## Must Check

- 主要導線が網羅されているか
- 状態別確認があるか
- 失敗ケースが含まれているか
- 画面崩れ観点があるか
- 既存機能への影響が確認されているか

## Related Skills

- `ui-regression-check`
- `e2e-test-review`
- `release-readiness-review`
