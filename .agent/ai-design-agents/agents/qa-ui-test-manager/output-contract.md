# Output Contract

## Required Sections

1. Summary
2. Scope
3. Findings
4. Risks
5. Recommended Changes
6. Decision

## Decision Values

- `approve`
- `approve_with_minor_changes`
- `needs_revision`
- `reject`

## Rules

- 指摘は観察事実ベースで記述する
- 重大度を High / Medium / Low で分類する
- 修正案は可能な限り具体化する
- 既存ルール違反がある場合は該当標準を明示する
- 不明点は推測せず Assumptions として分離する

## Findings Format

- ID
- Severity
- Category
- Observation
- Why it matters
- Recommendation
