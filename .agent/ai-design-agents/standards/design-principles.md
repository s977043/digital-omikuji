# Design Principles

## Purpose

UI の判断を個人の好みではなく、体験価値と一貫性で揃えるための基準です。

## Principles

- 情報階層を視覚で説明できること
- 余白は意図を持って使い、詰め込みで解決しないこと
- 主要導線は一目で分かること
- 状態差分は視認可能であること
- 実装は `DESIGN.md` と `docs/design-system/` の正本に従うこと

## Required Checks

- 主役が 1 つに定まっているか
- 視線誘導が破綻していないか
- 色とタイポグラフィの役割が分離されているか
- 画面サイズが変わっても意図が維持されるか
