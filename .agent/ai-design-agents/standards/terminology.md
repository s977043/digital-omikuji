# Terminology

## Purpose

UI 文言とレビュー表現の揺れを減らすための用語集の骨組みです。

## Preferred Terms

- `component`: 再利用可能な UI 部品
- `pattern`: 複数 component の組み合わせ
- `template`: 画面レベルの構成
- `finding`: 観察事実に基づく指摘
- `decision`: approve / approve_with_minor_changes / needs_revision / reject

## Rules

- 同じ概念に複数の名前を使わない
- ユーザー向け文言と開発用語を混在させない
- 略語を使う場合は初出で展開する
